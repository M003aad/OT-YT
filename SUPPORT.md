# Support

For help using OT-YT:

1. Review the [README](./README.md), including its installation and troubleshooting guidance.
2. Search [existing GitHub issues](https://github.com/M003aad/OT-YT/issues) for a similar question or problem.
3. If you cannot find an answer, [open an issue](https://github.com/M003aad/OT-YT/issues/new/choose) with the relevant browser version, YouTube page type, and steps to reproduce. Do not include passwords, private account information, or other secrets.

For suspected security vulnerabilities, use the private process in [SECURITY.md](./SECURITY.md), not a public issue.
