# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.0 | Yes |

Only the current release is supported with security updates. Please update to the latest release before reporting an issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub Private Vulnerability Reporting](https://github.com/M003aad/OT-YT/security/advisories/new) or email [188705139+M003aad@users.noreply.github.com](mailto:188705139+M003aad@users.noreply.github.com).

Include the affected version, a clear description of the issue, steps to reproduce it, and any relevant impact. Avoid including personal data or secrets.

## Response and Fix Expectations

- Acknowledgement target: **48 hours**.
- Patch target: **14 business days** after severity and impact have been assessed.

We will coordinate disclosure with the reporter where possible. Timing may depend on severity, complexity, and upstream fixes.
